# ResumeAI 🚀

An AI-powered Resume Builder and ATS Checker designed to help students, freshers, and professionals create ATS-friendly resumes quickly and efficiently.

Use your APIKEY at Resume.html page 
## 🌟 Features

* AI Resume Generation
* ATS Resume Score Checker
* Professional Resume Templates
* Mobile Responsive Design
* Clean User Interface
* Resume Download Functionality
* Privacy Policy & Terms Pages
* Contact & About Pages

## 🛠️ Technologies Used

### Frontend

* HTML5

* JavaScript

### AI Integration

* Groq API
* Llama 3 Model
